Neural Floorplan — demo asset notice
====================================

This file covers only `demo/`. It does not replace or amend the repository
root `NOTICE`; it extends the same reasoning to the demo bundle.


1. What is in demo/assets/
--------------------------

`demo/build_demo_assets.py` generates `demo/assets/samples/<id>/`, holding,
for each of three floor plans:

    01-input.png            preprocessed 512x512 input raster
    02-segmentation.png     seven-class segmentation map
    03-wall-graph.png       Raster-to-Graph nodes and edges, overlaid
    04-aligned.png          the same graph after orthogonal alignment
    05-hosting.png          opening-hosting debug overlay
    final_vector.svg        exported classified vector geometry
    final_vector.json       the same geometry plus stage metrics

These are copies of artifacts produced by the pipeline and stored under
`outputs/vectorization/phase4_vectorization/`; nothing is hand-edited,
retouched, or regenerated for presentation. They are gitignored here and
exist only after the builder is run - see section 2.


2. Dataset licensing
--------------------

The three source floor plans are CubiCasa5K renderings from the
`high_quality_architectural` subset:

  Kalervo, A., Ylioinas, J., Häikiö, M., Karhu, A., and Kannala, J.
  "CubiCasa5K: A Dataset and an Improved Multi-Task Model for Floorplan Image
  Analysis." Scandinavian Conference on Image Analysis (SCIA), 2019.
  https://github.com/CubiCasa/CubiCasa5k

International (CC BY-NC 4.0):

`demo/index.html`, `demo/assets/styles.css`, `demo/assets/app.js` and
`demo/build_demo_assets.py` are part of this repository and are therefore
**GPL-3.0-only**, like every other source file here.

Serving this page from another domain is a distribution of that GPL code. The
obligation is met by the source link in the page footer, which must be kept

  https://github.com/daegeun-kim/neural_floorplan

the sample data it carries is CC BY-NC 4.0 per section 2.
